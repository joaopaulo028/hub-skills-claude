## ❓ Perguntas que provavelmente você tem agora

<details>
<summary><strong>O que é uma Skill, em uma frase?</strong></summary>

Uma Skill é um **conjunto reutilizável de instruções + ferramentas** que o Claude pode invocar para executar uma tarefa especializada (revisar código, agendar agentes, configurar settings, etc.).
</details>

<details>
<summary><strong>Skill é a mesma coisa que slash command?</strong></summary>

São relacionados, mas não iguais. Slash commands (`/init`, `/review`) são uma das formas de **invocar** Skills. Você verá mais detalhes em [Como invocar](../01-fundamentos/como-invocar.md).
</details>

<details>
<summary><strong>Preciso saber programar para usar Skills?</strong></summary>

**Para usar**: não. Basta saber digitar `/nome-da-skill`.
**Para criar Skills avançadas**: ajuda saber o básico de markdown e (opcionalmente) shell script.
</details>

<details>
<summary><strong>Skills custam dinheiro?</strong></summary>

Skills em si são gratuitas — são apenas arquivos de instruções. O que custa é o **uso do Claude** que elas geram. Skills bem feitas podem **reduzir** custo (menos tentativas e respostas mais focadas).
</details>
