---

## 📦 Como usar esta pasta

Cada subpasta aqui é uma **Skill completa** — pode ser copiada direto para `~/.claude/skills/` e funcionar.

```bash
cp -r exemplos/resumo-do-dia ~/.claude/skills/
```

Depois invoque normalmente: `/resumo-do-dia`.

## 💡 Como contribuir para esta pasta

Toda vez que você criar uma Skill que ficar boa:

1. Copie a pasta de `~/.claude/skills/<nome>/` para cá
2. Adicione um `README.md` dentro da skill explicando:
   - Que problema ela resolve
   - Como você chegou nessa versão
   - O que melhorar futuramente
